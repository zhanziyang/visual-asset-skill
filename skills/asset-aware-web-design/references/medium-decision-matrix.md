# Visual medium decision matrix

## 1. Decision order

For each major section:

1. State the communication goal.
2. Assign an Asset Opportunity level.
3. Classify authenticity.
4. Select semantic asset type.
5. Compare viable media.
6. Inspect existing assets.
7. Apply source policy.
8. Select or generate candidates.
9. Let the chosen asset shape layout.

Do not start with a preferred tool or file format.

## 2. Medium evaluation dimensions

Score viable options qualitatively across:

| Dimension | Question |
|---|---|
| Authenticity | Does it truthfully represent the product, person, brand, or data? |
| Information fidelity | How accurately does it communicate the intended detail? |
| Emotional impact | Does it establish the intended feeling or real-world context? |
| Brand specificity | Could this visual belong only to this product, or to any generic SaaS? |
| Responsiveness | Can it adapt without losing meaning? |
| Interactivity | Does it need state, input, or live behavior? |
| Editability | Will content or structure change frequently? |
| Performance | Is the cost justified? |
| Accessibility | Can meaning be exposed without relying solely on the visual? |
| Production safety | Are provenance and usage rights clear? |
| Consistency | Does it belong to the current visual system? |

No single medium always wins.

## 3. Common semantic decisions

| Communication need | Prefer | Usually avoid as primary |
|---|---|---|
| Show what an existing product does | Real screenshot, recording, interactive preview | Generated dashboard, abstract illustration |
| Show a real integration or partner | Official brand asset | Generic icon, redrawn logo |
| Explain a process or architecture | Responsive HTML/SVG/Canvas diagram | Decorative illustration that obscures structure |
| Establish a lifestyle/use context | Owned/stock/generated photography or video | Location pin, generic feature icon, abstract gradient |
| Present factual metrics | Real data visualization | Invented chart or decorative numbers |
| Express an abstract brand metaphor | Illustration, 3D, procedural visual | Forced stock photography |
| Create subtle ambient depth | CSS, shader, texture, restrained motion | Heavy downloaded media with no added meaning |
| Frame actual Product UI | Device/browser mockup plus real screenshot | Fake UI drawn into a mockup |
| Establish founder/team trust | Real portraits | AI faces or unrelated stock presented as factual |
| Show a physical product | Photography or accurate 3D | Approximate generated form when accuracy matters |
| Label repeated actions or simple categories | One coherent 2D icon family; 3D icons only for sparse brand moments | Mixed icon packs, emoji, or feature icons used as evidence |
| Let users inspect spatial form or configuration | Optimized interactive 3D with a poster fallback | Heavy 3D scene when a fixed render communicates equally well |
| Explain responsive, editable structure | Code-rendered HTML/SVG/Canvas | Sourced illustration that hides relationships |

## 4. Section archetypes

These are starting points, not automatic prescriptions.

### Product hero

Typical opportunity: `REQUIRED`.

Prefer:

- real product video;
- real screenshot or UI sequence;
- product/object render where the object itself is the product.

Allow supporting:

- device/browser frame;
- restrained gradient, texture, or procedural ambience;
- motion treatment.

Reject:

- fake UI when a product exists;
- generic SaaS dashboard art;
- abstract glow as the only visual evidence.

### Consumer or lifestyle hero

Typical opportunity: `HIGH`.

Prefer photography, video, product-in-context, or a distinctive illustration system depending on brand strategy.

Let genuine negative space determine copy placement.

### Feature demonstration

Typical opportunity: `HIGH` or `REQUIRED`.

Prefer Product UI, before/after, interaction sequence, small demo video, or explanatory visual.

A generic icon is usually insufficient when the feature can be shown.

### Use-case section

Typical opportunity: `HIGH`.

Prefer environmental photography/video, user-context imagery, object scenes, or product-in-context. Use illustration only when the brand world is intentionally illustrative.

### How it works

Typical opportunity: `HIGH`.

Prefer a diagram, animated process, screenshot sequence, or lightweight interactive explanation.

Do not default to three equal cards with numbered circles.

### Integrations

Typical opportunity: `REQUIRED` when named integrations are claimed.

Use official brand assets. Do not replace them with generic glyphs.

### Testimonials and social proof

Typical opportunity: `HIGH`, but authenticity governs.

Use real portraits/logos only when provided and attributable. Without real identity assets, use a well-designed text quote or anonymous aggregate rather than inventing a person.

### Metrics and outcomes

Typical opportunity: `MEDIUM` to `HIGH`.

Use real data, a restrained chart, or strong typography. Do not create decorative charts without data meaning.

### Pricing

Typical opportunity: `LOW`.

Clarity, typography, and comparison usually matter more than imagery. Product or trust assets may support but should not compete.

### FAQ, legal, documentation

Typical opportunity: `NONE` or `LOW`.

Preserve legibility and whitespace. Do not add assets merely to break up text.

### Final CTA

Typical opportunity: `LOW` to `MEDIUM`.

Reuse a coherent product, brand, or motion motif when it reinforces conversion. Do not introduce an unrelated new visual language.

## 5. Primary vs supporting use

An asset can be appropriate as support but weak as the primary visual.

Examples:

| Asset | Primary use | Supporting use |
|---|---|---|
| CSS gradient | Sometimes, for atmospheric or typographic concepts | Frequently |
| Generic icon | Rarely | Labels and controls |
| Official logo | Integrations and trust | Navigation/footer |
| Product screenshot | Product evidence | Cropped detail accents |
| Photography | Lifestyle/emotional storytelling | Section texture or crop |
| Diagram | Explanation | Small conceptual support |
| Shader/WebGL | Generative brand experience | Ambient background |

## 6. Stop rule

After evaluating an opportunity, omit the asset when it does not improve at least one of:

- understanding;
- credibility;
- emotion;
- identity;
- narrative;
- interaction;
- conversion.

Whitespace and strong typography are valid final decisions.
